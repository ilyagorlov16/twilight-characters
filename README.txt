ДОСЬЕ ПЕРСОНАЖЕЙ КИНОСАГИ «СУМЕРКИ» (5 фильмов)
=================================================

СОСТАВ ПАПКИ
  index.html   — страница-каталог (открывается двойным кликом в любом браузере, работает офлайн)
  images/      — 55 локальных JPG-кадров (300x400), по одному на персонажа с найденным кадром
  data.json    — машиночитаемые данные всех 95 персонажей
  README.txt   — этот файл

КАК ОТКРЫТЬ
  Просто откройте index.html в браузере (Chrome / Firefox / Edge).
  Важно: не перемещайте index.html отдельно от папки images/ — фото подключены относительными путями.

ЧТО ВНУТРИ
  95 персонажей всех пяти фильмов: «Сумерки» (2008), «Новолуние» (2009), «Затмение» (2010),
  «Рассвет: Часть 1» (2011), «Рассвет: Часть 2» (2012).
  По каждому: фото (локальный кадр), имя, возраст, год рождения, раса
  (вампир / вампир-новорождённый / вампир-кочевник / оборотень / человек / гибрид),
  клан или группа, актёр, список фильмов появления.
  Фильтры: раса, клан/группа, фильм, поиск, «только с фото». Ниже — сводная таблица и блок фактчекинга.
